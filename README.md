# Бронирование переговорной

Одна переговорная, рабочее время 09:00–20:00. Все операции выполняются GET-запросами, ответы — JSON с HTTP-кодами.

## Запуск

Python 3.11+ и PostgreSQL 14+.

```sh
pip install -r requirements.txt
export DATABASE_URL='postgresql://user:password@localhost:5432/booking'
uvicorn app:app --host 0.0.0.0 --port 8000
```

Таблица и индекс создаются автоматически при запуске. DATABASE_URL хранится только в переменных окружения, не в Git. Render: runtime Python, build `pip install -r requirements.txt`, start `uvicorn app:app --host 0.0.0.0 --port $PORT`.

## API

- `/book?name=Анна&date=2026-11-10&from=10:00&to=11:00` — 201 и объект booking с уникальным числовым id.
- `/list?date=2026-11-10` — 200 и bookings, отсортированные по началу; пустой день даёт пустой массив.
- `/cancel?id=1` — 200 и отменённая бронь; повторная отмена — 404.
- `/health` — проверка приложения и подключения к базе.
- `/docs` — автоматически сгенерированная документация маршрутов; параметры передаются в URL по примерам выше.

400: неверный формат, отсутствующие/повторные/неизвестные параметры, невозможная дата, пустое имя, недопустимый интервал. 409: пересечение с существующей бронью. 503: база временно недоступна.

Дата строго ГГГГ-ММ-ДД, время строго ЧЧ:ММ. Интервалы полуоткрытые: 10:00–11:00 и 11:00–12:00 разрешены. Бронь с началом раньше 09:00 или окончанием позже 20:00 запрещена. Прошедшие даты разрешены: запрет не задан в ТЗ. Время локальное для переговорной, без автоматического перевода часовых поясов.

## Сохранность и конкурентность

Данные хранятся в PostgreSQL отдельно от процесса приложения и сохраняются при перезапуске и перевыкладке веб-сервиса. Проверка пересечения `existing.start < new.end AND existing.end > new.start` и вставка выполняются в одной транзакции. Транзакционная advisory-блокировка одной переговорной сериализует создание и отмену между всеми экземплярами этого приложения. Все SQL-параметры передаются отдельно от текста запроса. Identity-номера не переиспользуются после удаления (пропуски допустимы).

Важно: это бесплатное демо Render. База создана 28.10.2026 и истекает 27.11.2026; бессрочное хранение на этом тарифе не гарантируется. Для дальнейшей работы нужна миграция или платная постоянная база. Бесплатный веб-сервис может засыпать, поэтому первый запрос может быть медленным.

## Проверка

```sh
python -m unittest -v
```

Unit-тесты проверяют валидацию, календарные даты, границы рабочего дня и форматирование. Дополнительно при проверке развёрнутого сервиса: создать бронь, повторить её (409), проверить частичное пересечение (409), смежную бронь (201), список, отмену, повторную отмену (404), перезапуск и два одновременных запроса на один интервал (один 201, другой 409).

## Ограничения безопасности

По ТЗ создание и отмена используют GET, хотя для production это должны быть POST/DELETE с авторизацией и CSRF-защитой. Ответы имеют Cache-Control: no-store. Любой посетитель демо может просматривать и отменять брони; не используйте реальные персональные данные. URL с именем может сохраняться в истории браузера и логах. Переход по ссылке бронирования повторно создаст новую попытку брони, предварительная загрузка ссылок может вызвать операцию. Не публикуйте ссылки создания/отмены там, где работают автоматические просмотрщики.
